# W Menu

Press the round **W** icon - bottom left of the main menu, or bottom left of the pause menu - to open the click GUI.

## Modules

| Module | What it does |
| --- | --- |
| **CBFH** | The main module. Any click you make is captured between frames and re-applied exactly on a frame boundary, then held for the frame window you set (1 - 20 frames). The jump fires on the earliest frame it can, so the click is frame perfect. It never checks your state, so it clicks even when that kills you. |
| Frame Counter | Draws the current frame number on screen while you play. |
| Dim Background | Darkens the game behind the click GUI. |
| UI Sounds | Click feedback whenever you toggle a module. |
| Compact Rows | Tighter rows and a smaller panel. |

## Setting the frame window

CBFH has a drag slider for the window: 1 to 20 frames. Your value is saved immediately, so it is still there next launch.

*1 frame* is the tightest single-frame click. Higher windows keep the input held longer, so the jump fires on the first frame the game allows it inside that window.
